# MedSync QA and Homologation

## Instructions

1. Read `docs/08-quality/README.md`.
2. Read `qa/README.md` when test cases or QA plans are needed.
3. Do not mark tests as passed without evidence.
4. Include negative tests for profile access, tenant isolation, clinical data access, consent, video entry, and B2B privacy.
5. Keep production blocked until required approvals and evidence exist.

## Required references

- `docs/08-quality/QA_CHECKLIST.md`
- `qa/test-plan.md`
- `qa/test-cases.md`
- `qa/security-test-cases.md`
- `qa/lgpd-test-cases.md`
- `qa/b2b-test-cases.md`

## Output contract

- List tests planned or required.
- List evidence required.
- Identify blockers and residual risks.
- Confirm whether the work is documentation-only or test execution.
