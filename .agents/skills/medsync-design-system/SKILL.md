# MedSync Design System

## Instructions

1. Read `docs/02-design/DESIGN_SYSTEM.md`.
2. Read `COMPONENT_LIBRARY.md`, `UI_STATES.md`, and `DESIGN_SYSTEM_READINESS.md` as needed.
3. Define component behavior without creating implementation code.
4. Ensure every component has loading, empty, error, disabled, and permission-aware states where applicable.
5. Keep tokens as `TODO` until visual approval exists.

## Required references

- `docs/02-design/DESIGN_SYSTEM.md`
- `docs/02-design/COMPONENT_LIBRARY.md`
- `docs/02-design/ACCESSIBILITY_GUIDELINES.md`
- `docs/02-design/RESPONSIVE_GUIDELINES.md`

## Output contract

- List components affected.
- List required states.
- Identify accessibility and responsive risks.
- Confirm no frontend code was created.
